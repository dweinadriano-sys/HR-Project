# Time-to-Hire Analysis for Niche IT Roles in the Philippines

## Problem Statement
The average time-to-hire is 31.8 days. This should be reduced to 25 days or less.

## Data
A synthetic two-year recruitment dataset covering January 2024 to December 2025, containing 1,200 candidate application records across IT, technical, corporate, and other specialized roles in the Philippines.

The dataset includes candidate information, job roles, recruitment sources, work arrangements, recruiters, recruitment-stage dates, offer outcomes, and time-to-hire metrics.

## Methodology
### Data Cleaning
  1. Identified and removed duplicate records.
  2. Handled missing values.
  3. Standardized text formatting and category labels.
  Corrected data types and date formats.
  4. Validated recruitment dates and calculated fields.
  5. Recalculated time-to-hire from the underlying recruitment dates.

### Exploratory Data Analysis
  1. Calculated average and median time-to-hire.
  2. Analyzed time-to-hire by year, month, role, recruiter, and sourcing channel.
  3. Examined recruitment-stage durations to identify potential bottlenecks.
  4. Compared hiring timelines across work arrangements and candidate characteristics.

### Data Visualization
  1. Created charts to identify trends and recruitment bottlenecks.
  2. Compared actual time-to-hire against the 25-day target.
  3. Developed visualizations showing differences across roles, recruiters, and sourcing channels.
